## 变更范围

- **HTTP Client 连接复用**（`src-tauri/src/utils/http.rs`）：按主机、超时和解析出的本地路由复用 reqwest blocking Client，使 TCP/TLS 连接池可在多个请求间保留。路由变化时重新创建客户端；保留既有 Windows 国内直连/no_proxy、连接超时与请求超时策略。
- **TRAE 账号模型目录缓存**（`src-tauri/src/modules/trae_model_pool.rs`）：按账户 ID、上游地址和当前 Token 指纹进行内存缓存；成功目录 TTL=300 秒、上限 128 项，失败不缓存。缓存未命中目标模型时主动刷新；认证/额度错误和可能的模型参数错误失效缓存；模型目录手动刷新也会清缓存。
- **不调整**：指定模型、账号偏好/冷却与故障切换规则、流式 SSE 协议、Prompt 内容、工具调用、令牌额度和 UI 操作流程。
