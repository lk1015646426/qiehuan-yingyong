# WorkBuddy 状态刷新修复实施计划

**目标：** 修复积分、今日奖励、连续签到无法显示或刷新问题。

**架构：** 后端分别处理积分与签到状态，允许部分成功；签到状态增加旧接口回退。前端在账号快照变化、导入、切换和失败后清理/重试状态，并保持已成功数据。

**技术栈：** Rust/Tauri、reqwest、Serde、React、Zustand、Node test。

## 任务

- [ ] 为后端解析和部分成功行为补充失败测试。
- [ ] 为签到状态回退、`daily_credit` 兼容和认证字段变化补充测试。
- [ ] 实现后端部分成功与回退，保留可用字段并返回可诊断错误。
- [ ] 实现前端状态失效、失败重试和导入/切换后的刷新。
- [ ] 运行 WorkBuddy Rust/TypeScript 测试与构建检查。
