## 补充诊断：2026-11-15 后续

隔离代理只记录请求字段、消息角色数量、系统文本长度及指定句子的布尔存在性，不保存提示词或凭据；原版 Harness 0.2.2-rc.3 的主 Agent 请求含 1 条 system、4 条 user、23 个工具，系统正文约 2913 字符，包含 Harness 名称；对应请求返回 400。后台短请求（1 system、1 user、无 tools）另一次返回 200，不能作为主 Agent 请求成功的证据。

保持系统指令和工具定义原样，删除可选 store 与 stream_options 仍 400；合并相邻 user 消息仍 400；仅用于隔离定位而不带工具定义仍 400。每种属于独立的隔离诊断，不用于正式服务自动重放。结果没有证明唯一触发因素；也不能把删工具作为可用 Agent 方案。详细结构报告在 `.tmp/wb-shape-*/shape-report.json`。

更正：上节提到的单句措辞测试，结构探针显示本机实际 Agent system 不含该条精确原句。因此该尝试很可能没有应用改写，不能据此判断改写后仍失败。未测试其他变更 Harness 身份或整体替换 system 的回退。

WorkBuddy 状态新增本地已选模型 ID，只用于在模型目录请求失败时显示已有选择；TRAE 已有同类状态字段。页面目录请求失败时仍保留已获取的服务状态及本地选择，并显示目录不可用；不会伪造在线模型目录。对应离线状态测试通过。当前前端 57 项、Rust 339 项通过（13 忽略），前端构建通过。没有使用 Computer Use。
